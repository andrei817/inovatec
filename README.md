🎉 SGE — InovaTec

Sistema de Gestão de Eventos

O SGE — InovaTec é um sistema desenvolvido para facilitar a organização e divulgação de eventos, reduzindo a necessidade de processos em papel e tornando o gerenciamento mais prático, organizado e acessível.

A plataforma é dividida em dois perfis principais: Produtor e Cliente, cada um com diferentes funcionalidades dentro do sistema.

🚀 Funcionalidades

👨‍💼 Produtor

O produtor possui acesso ao sistema administrativo e é responsável pelo gerenciamento dos eventos.

Principais funcionalidades:

➕ Cadastrar eventos

✏️ Alterar informações dos eventos

❌ Cancelar/excluir eventos

⚠️ Reportar problemas

📋 Visualizar e gerenciar informações dos eventos

👤 Cliente

O cliente possui acesso à área de visualização dos eventos através de um carrossel interativo, permitindo consultar informações importantes de forma prática.

Entre as informações apresentadas estão:

📌 Nome do evento

📅 Data

🕐 Horário

🎨 Tema

🍽️ Buffet

🎓 Escolaridade

ℹ️ Outras informações relevantes sobre o evento

🛠️ Tecnologias utilizadas

PHP — desenvolvimento da aplicação e funcionalidades do sistema

HTML5 — estrutura das páginas

CSS3 — estilização e interface

JavaScript — interatividade da aplicação

SQL — armazenamento e gerenciamento dos dados

🎯 Objetivo do projeto

O projeto foi desenvolvido com o objetivo de criar uma solução digital para a organização e gerenciamento de eventos, substituindo processos que poderiam depender de papel e facilitando o acesso às informações.

A proposta é tornar a organização dos eventos mais prática, rápida e fácil, tanto para os produtores quanto para os clientes.
